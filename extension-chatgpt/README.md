# Task Pulse ChatGPTタブ — 同期モード

## 状態
ChatGPT専用WorkerとD1は、2026-10-15のユーザー承認後に配備しました。
Codexのネイティブ登録も同じ専用Workerの別テーブルを使います。
既存Claude用handoffの鍵やDBは共有しません。Chrome拡張の導入と実チャット1件の自動登録も確認済みです。

## 対象PJと更新
- **「Claudeセカンドオピニオン」PJ内だけ**が対象です。別PJ・PJ未所属は登録しません。所属は固定PJ IDで判定し、題名の一致では判定しません。
- バージョンは **0.5.0**。更新後はChromeの「Task Pulse — ChatGPT チャット登録」カードで再読み込みし、0.5.0と表示されることを確認してからChatGPTタブも再読み込みします。
- 追跡済みチャットをPJ外のURLで開いた場合、IDと観測時刻だけで登録範囲から外します。移動先PJの題名・本文・PJ名は送信しません。未追跡のPJ外チャットはサーバーへ送りません。開かれていないチャットの移動は履歴を巡回しないため検知できません。

## PC：会話の自動登録
- Chrome拡張の `extension-chatgpt` フォルダを開発者モードで読み込みます。
- 運用者の非公開パッケージに登録専用設定が入っている場合、鍵の貼り付けは不要です。公開ソースの設定は空なので、その場合だけ「オプション」でCAPTURE_TOKENを設定します。
- 対象PJ内のChatGPTチャットを開くと、拡張バックグラウンドがURL・タイトル・ブラウザ観測時刻を送ります。既存チャットへの新しい指示も、送信操作と新しい発言IDを確認して指示時刻を送ります。会話本文・Cookie・ChatGPTのAPIキーは読みません。
- 通信不可・鍵未設定なら未送信キューに残し、5分ごとに再試行します。失敗後に勝手に消しません。
- 登録専用の鍵では一覧の閲覧・メモ更新・手動の外す/戻す操作はできません。「外す」後に新しい指示を送った場合は一覧へ自動復帰します。開くだけ・題名変更では復帰しません。端末とサーバーの時計が合っていることを前提に指示時刻と閉鎖時刻を比較し、未来時刻は復帰に使いません。
- `chrome.storage.local`は`TRUSTED_CONTEXTS`へ制限し、ページに入るcontent scriptは鍵を読めません。

## taskPulseでPC・iPhone共通一覧を使う
- 既存のブックマーク URL に、**# の後ろ**のパラメータ `gptread=...` と `gptwrite=...` を追加します（既存graph/write値はそのまま維持）。
- 同じブックマークをiPhoneで開けば、同じCloudflareの台帳を読む構成です。
- gptreadのみの場合は読み取り専用です。gptread未指定なら従来どおり端末ローカルの一覧です。
- 現在PC内にある過去のメモや「外す」記録は、自動的にネットへ送られません。同期モードで **「この端末の既存記録を同期」** を本人が押した場合だけ、同期台帳にまだないIDを作成します。既存IDのメモ/閉鎖状態は上書きせず、ローカル記録も消しません。
- ChatGPTの共有リンク（/share/）は登録しません。ChatGPTアプリ本体の会話を消す操作はありません。

- 本番Worker/D1の配備・認証境界は確認済みです。旧版で登録したCodexの13件はPJ未所属のため、今回の限定で表示対象外になります。Chrome実チャット1件の通常登録も確認済みです。0.4.0で既存チャットへの新しい指示による復帰も実機確認済みです。今回のPJ限定・iPhone・オフライン再送の実機確認は別の項目です。
- Node試験、実WranglerローカルD1のHTTP/CAS試験、Codex collectorからDBまでの題名変更試験は通過しています。
- ChatGPTの生成中/出力完了ランプは未実装。
- 公開ページに秘密鍵を埋めないでください。URLフラグメント内の鍵はブラウザ履歴・同期・同一originのコードから読めるbearer credentialです。
